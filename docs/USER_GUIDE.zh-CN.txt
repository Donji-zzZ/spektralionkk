spektralionkk 1.4 —— 适用于 Windows 的光谱胶片与印放模拟
==================================================================

语言
  English 或简体中文。软件会使用你在安装程序中选择的语言；之后可随时在 视图 ▸ 语言 中更改
  （重启后生效）。

布局（Lightroom 风格）
  左侧  导航器（适合 / 填满 / 100% / 200%；点击或拖动可移动画面）、风格、历史记录、拷贝… / 粘贴
  顶部  打开… / 文件夹… / 导出…；导出进度显示在“导出…”旁边
  中间  照片；工具栏：修改前（\）、前后对比分屏（Y）、溢出（J）；胶片栏
  右侧  直方图和相机信息、工具（裁剪 R、白平衡吸管 W），然后是 胶片与相纸（胶片、相纸、黑白反差等级）、
        胶片边框（胶片条和日期后背）、基本（白平衡、曝光、对比度、高光、阴影、白色色阶、黑色色阶、
        清晰度、自然饱和度、饱和度）、色调曲线、颜色混合器（HSL）、颜色分级、放大机、胶片与颗粒、
        效果（暗角、眩光、柔焦滤镜、创意 LUT）、细节、镜头；同步… / 重置

胶片与相纸
  胶片是照片曝光、冲洗所用的材料。相纸是印放负片的相纸，和暗房里一样：负片是反相的橙色影像，相纸把它
  变成最终的照片，每种相纸都有自己的反差和色彩（Portra Endura 柔和自然，Ultra Endura 浓烈有力，
  Ektacolor Edge 是明亮的冲印店照片，Crystal Archive 是富士的冲印相纸，Vision 2383 / 2393 是电影拷贝片）。
  “直接扫描”不经过印放——反转片就是这样观看的。相纸菜单下方有所选相纸的说明。

白平衡
  每张照片一开始都使用相机自身的（原照）白平衡；胶片和风格都不会改变它。可在 基本 ▸ 白平衡 中更改
  （自动、预设、色温 / 色调），或使用吸管（W）。

工作流程
  1. 打开照片或文件夹（Ctrl+O / Ctrl+Shift+O），或把文件拖进来。支持 RAW（NEF、CR2/CR3、ARW、RAF、ORF、
     RW2、DNG 等，包括压缩 RAW）、JPEG、TIFF、PNG、EXR。
  2. 点击左侧的一个风格，或在“胶片与相纸”中选择胶片和相纸（“数码（无胶片）”会关闭胶片模拟）。
  3. 在“基本”和其他面板中微调，也可以在直方图上左右拖动，直接调整黑色色阶、阴影、曝光、高光或白色色阶。
  4. 裁剪（R）：拖动角、边或框内区域；选择比例（“自由”表示不锁定）。
  5. 导出（Ctrl+E）：JPEG / 16 位 TIFF / PNG，色彩空间可选 sRGB、Display P3、Adobe RGB、ProPhoto、Rec.2020，
     可选择是否包含胶片边框和日期。导出在后台进行；“导出…”旁边（左上角）的细进度条显示进度，✕ 可停止，
     “显示”可打开所在文件夹。

速度
  滑块会实时更新画面：色彩、影调、曝光、白平衡、胶片、相纸、曲线、HSL 和 LUT 都通过查找表计算（每帧几毫秒，
  任何 CPU 都可以，不需要显卡）。松开滑块后，全质量渲染会加上颗粒、光晕、成色剂扩散和锐化。颗粒只在能看到的
  地方模拟——100% 缩放和导出时（也可在“视图”菜单中设为始终显示）。渲染以低于正常的优先级运行，并留出两个 CPU
  核心，让电脑保持流畅。在一台电脑上首次启动时会编译处理内核（约 30 秒，只需一次）。
  导出：胶片以全分辨率并行分带冲洗（颗粒、光晕、成色剂）；相纸 / 扫描部分来自用 spektrafilm 自身算法为每个风格
  烘焙一次的查找表（与逐像素计算相比 ΔE00 ≈ 0.03），因此在 12 核电脑上导出一张 42 MP 的 RAW 约需 40 秒。

预设与 LUT
  文件 ▸ 导入预设与 LUT…（或在风格列表中右键）可读取 Lightroom / Camera Raw 预设（.xmp、.lrtemplate）、
  .cube LUT 和 spektralionkk 预设（.sprkpreset）。导入的预设显示在“我的风格”中。这里没有对应项的 Lightroom
  设置（例如纹理、去朦胧、蒙版）会被跳过并列出。可以把任何风格或当前设置导出为 .sprkpreset 来分享。
  效果 ▸ 创意 LUT ▸ 导入… 可为单张照片添加 .cube LUT。

胶片栏
  右键点击一张或多张照片可使用：星级（按键 0–5）、选取 / 排除旗标（P / X / U）、应用风格、拷贝 / 粘贴 / 同步
  设置、重置、旋转、导出、在资源管理器中显示、用默认程序打开、复制文件路径、从图库中移除，以及 显示 ▸
  （全部 / 仅选取 / 隐藏排除 / 按星级）。小红点表示照片已修改。

胶片边框与日期后背
  打开“胶片边框”标题上的开关（右侧面板，“胶片与相纸”下方）。胶片条会按比例在画面周围印出胶片：135 带齿孔
  （透光扫描的白色或黑色）、胶片自带的片边字码、片号和 DX 码；120 带片基边字样。“胶片画幅”用于选择片门——
  半格、135、XPan、645、6×6、6×7、6×8、6×9、6×12、6×17、4×5——画面会按它取景（6×6 是正方形；可用裁剪工具
  移动）。其他样式：锉边底片夹、幻灯片框、白边。日期后背：135 在画面内印橙色 LED 日期，120 印在片边，
  此时“拍摄参数”还会加上快门、光圈和焦距。
  视图 ▸ 显示胶片边框（Shift+F）只在预览中隐藏边框；导出对话框有单独的“包含胶片边框与日期”复选框（默认勾选）。

压缩 RAW
  索尼、佳能（CR3 和 C-RAW）、富士、尼康、松下和 DNG 的无损及有损压缩 RAW 文件都可以正常打开。少数最新的编码
  （尼康高效率 RAW、JPEG XL DNG）RAW 解码器暂不支持；遇到这些文件时，软件会改为编辑相机内嵌的全尺寸 JPEG，
  并给出提示。

风格
  相机风格（GR、徕卡和富士风格）是用本软件的胶片模拟和后期工具做出的近似效果，并非厂商的官方配置。
  spektralionkk 与理光、徕卡或富士均无关联。

检查电脑：  开始菜单中的“sprktralionkk self-test”（或 sprktralionkk.exe --selftest）。
你的修改：  %LOCALAPPDATA%\sprktralionkk\library.json（日志：sprktralionkk.log）
LUT：       %LOCALAPPDATA%\sprktralionkk\luts（文件 ▸ 打开预设与 LUT 文件夹）
